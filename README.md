# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

- `index.html` — главная страница;

- `category.html` — страница категории «Новинки»;

- `order.html` — форма оформления заявки;

- `sitemap.xml` — простая карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Инструкция по просмотру проекта

Опубликованная версия:

3. Открыть каталог, затем страницу товара — проверить карточки и таблицу характеристик.

Локальный запуск:

1. Клонировать репозиторий: `git clone https://github.com/gothplug/kr1_front.git`
2. Перейти в папку проекта: `cd kr1_front`
3. Открыть файл `index.html` в браузере.

## Описание обязательных страниц

### `index.html` — главная страница

Содержит hero-блок с заголовком и кнопкой перехода к товарам, раздел «Преимущества проекта»
с якорным идентификатором `advantages`, раздел «Популярные товары» с сеткой карточек
и дополнительный блок `<aside>` с информацией о проекте. Здесь же размещено модальное
окно `<dialog>` с формой заявки и сообщение об успешной отправке.

### `catalog.html` — каталог товаров

Содержит статический блок фильтров (категории и диапазон цены) и список карточек товаров,
выстроенных через CSS Grid. На странице девять карточек, у трёх из них есть бейджи
«Хит», «Новинка» и «Скидка». Каждая карточка ведёт на страницу товара.

### `product.html` — карточка товара

Содержит изображение товара с бейджем, описание, артикул, наличие, оценку покупателей,
цену и кнопки «Оформить заявку» и «Вернуться в каталог». Ниже размещены расширенная
таблица характеристик товара, список комплектации, таблица сравнения тарифов доставки
и блок условий возврата. Обе таблицы оформлены через `caption`, `thead` и `tbody`.

### `order.html` — форма оформления заявки

Содержит форму заявки с полями имени, e-mail, телефона, даты связи, темы заявки,
комментария и согласия на обработку данных. Обязательные поля помечены атрибутом
`required`, e-mail проверяется через `type="email"`, телефон — через атрибут `pattern`.

### `contacts.html` — контакты

Содержит контактную информацию (телефон, e-mail, адрес) и блок обратной связи
со ссылкой на форму заявки на странице `order.html`.

### Общие элементы всех страниц

Каждая страница проекта, включая дополнительную `category.html`, имеет уникальный `title`,
собственный `meta description`, единое меню навигации в шапке, один тег `<main>`,
общий подвал и подключённый внешний файл стилей `css/style.css`.

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке;
- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-logo` — логотип;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `product-card` — карточка товара;
- `products-grid` — сетка товаров;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `product-detail` — карточка товара на отдельной странице;
- `product-table` — таблица характеристик;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `catalog-categories` — переключатель категорий каталога;
- `review-card` — карточка отзыва;
- `faq` — блок часто задаваемых вопросов;
- `to-top` — фиксированная кнопка «Наверх».

## Базовое позиционирование

- `position: relative` — карточка товара как контейнер для бейджа;
- `position: absolute` — бейдж «Хит», «Новинка», «Скидка» в карточке;
- `position: sticky` — блок фильтров на странице каталога;
- `position: fixed` — кнопка «Наверх»;
- `z-index` — бейдж карточки, фильтры, модальное окно, фиксированная кнопка.

## Самостоятельные доработки

Помимо шагов, описанных в методических указаниях, в проект добавлено:

- дополнительная страница категории `category.html` со списком товаров категории «Новинки»;
- блок «Отзывы покупателей» на главной странице — карточки с `blockquote` и `cite`;
- блок «Часто задаваемые вопросы» на главной странице на элементах `details` и `summary`
  (работает без JavaScript);
- переключатель категорий каталога со ссылками на страницу категории;
- расширенный каталог: девять карточек товаров вместо базовых трёх;
- собственные изображения товаров в карточках с атрибутами `width`, `height`
  и `loading="lazy"`;
- подробная страница товара: артикул, наличие, оценка, комплектация, условия возврата,
  расширенная таблица характеристик и таблица сравнения тарифов доставки;
- ссылка «Подробнее» в карточках на главной странице в дополнение к кнопке «Заказать»;
- улучшенное модальное окно: кнопка закрытия в углу, показ выбранного товара,
  закрытие по клику вне окна, плавное появление, перевод фокуса в первое поле;
- улучшенная доступность формы: подсказка формата телефона связана с полем через
  `aria-describedby`, добавлены `autocomplete` и `role="status"` для сообщения об отправке;
- бейджи состояний товара «Хит», «Новинка», «Скидка» на основе БЭМ-модификаторов;
- фиксированная кнопка «Наверх» на всех страницах;
- «липкий» блок фильтров на странице каталога;
- хлебные крошки на внутренних страницах;
- сообщение об успешной отправке заявки;
- подсветка ошибочных полей формы через атрибут `aria-invalid`;
- адаптивные медиазапросы для сетки товаров и раскладки каталога;
- теги Open Graph и файл `sitemap.xml`;
- собственное изображение-превью `images/preview.jpg` для Open Graph.

Самостоятельные доработки не меняют требования контрольной работы: проект остаётся
многостраничным HTML/CSS-сайтом без CSS-фреймворков и без полноценной
JavaScript-интерактивности.
